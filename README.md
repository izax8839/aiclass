# 🚀 AI Nexus Academy - 인공지능 교육 홈페이지

실전 프로젝트 중심의 차세대 AI 교육 플랫폼 웹사이트입니다.  
비전공자 업무 자동화부터 개발자를 위한 LLM 서비스 개발 및 딥러닝 구현까지 4대 맞춤형 코스와 상세 페이지를 완벽하게 제공합니다.

---

## 📂 사이트 파일 구성

```
aiclass/
├── index.html                   # 메인 랜딩 페이지 (Hero, 특장점, 코스 프리뷰, 포트폴리오, 강사진, 수강후기, FAQ, 모달)
├── courses.html                 # 전체 과정 안내 및 비교 페이지 (난이도, 기간, 선수 지식, 수강료 비교표)
├── course-generative-ai.html     # [과정 1] 생성형 AI & 프롬프트 엔지니어링 마스터 상세
├── course-business-automation.html # [과정 2] 업무 자동화 & 노코드 AI 비즈니스 실전 상세
├── course-deep-learning.html     # [과정 3] 파이썬 & 딥러닝/머신러닝 코어 부트캠프 상세
├── course-llm-agent.html         # [과정 4] LLM 서비스 개발 & RAG·AI 에이전트 구축 실무 상세
├── apply.html                   # 수강 신청 및 1:1 무료 상담 접수 전용 페이지
├── css/
│   └── custom.css               # Pretendard 웹폰트, 글래스모피즘, 네온 글로우, 커스텀 애니메이션

    ├── data.js                  # 커리큘럼, 강사진, 수강생 리뷰, FAQ 데이터셋

```

## 🌟 주요 기능 및 특징

1. **설치/빌드 없이 즉시 실행 가능**
   - 별도의 `node_modules` 설치나 빌드 과정 없이 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 사파리 등 원하는 브라우저에서 바로 열 수 있습니다.
2. **트렌디한 하이테크 디자인**
   - 다크 모드 기반의 딥 테크 비주얼, 은은한 네온 글로우와 백드롭 블러(글래스모피즘) 효과 적용.
   - 프리텐다드(Pretendard) 폰트 적용으로 뛰어난 한글 가독성 보장.
3. **완벽한 반응형 웹 (Responsive Design)**
   - 모바일, 태블릿, 데스크톱 화면 크기에 따라 최적화된 레이아웃 및 모바일 햄버거 메뉴 제공.
4. **4대 핵심 과정별 상세 페이지 제공**
   - **생성형 AI & 프롬프트 마스터 (4주)**: 비전공자/직장인을 위한 ChatGPT, Claude, Midjourney 실무 활용.
   - **업무 자동화 & 노코드 실전 (6주)**: Make, Zapier, n8n과 LLM 결합으로 반복 업무 0화.
   - **딥러닝 코어 부트캠프 (8주)**: 선형대수부터 PyTorch 기반 CNN, ResNet, Transformer 구현.
   - **LLM 서비스 개발 & RAG 에이전트 (8주)**: LangChain, LangGraph, LlamaIndex, Vector DB 기반 엔터프라이즈 시스템.
5. **풍부한 인터랙션**
   - 카테고리 필터링 탭
   - 빠른 커리큘럼 확인 모달 팝업
   - 주차별 상세 커리큘럼 및 FAQ 아코디언
   - 수강 신청/상담 접수 시 즉각적인 확인 알림 토스트

## 🖥️ 바로 확인하는 방법

1. **파일 직접 열기**:
   - `aiclass` 폴더 내의 `index.html` 파일을 더블 클릭하여 웹 브라우저에서 엽니다.
2. **로컬 웹 서버로 열기 (선택 사항)**:
   - 터미널에서 다음 명령어를 실행하면 `http://localhost:8000`에서 확인하실 수 있습니다:
   ```bash
   python -m http.server 8000
   ```
